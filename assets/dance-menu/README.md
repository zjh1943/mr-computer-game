# Dance entry and selection assets

- `source-logo.png`, `title-characters.png`, `title-frames.json` and menu/count-in sounds come from the existing Yet Another Sprunki FNF Mod V2.1 source archive. Title characters are the original Pinki / Simon / Gray idle frames, not an animated copy of the supplied screenshot. See `../dance-reference/README.md` for attribution.
- `sprunki-preview.png` is the third reference image attached by the user on 2026-11-16, used at their request as the first game preview.
- Menu previews use the actual YouTube video cover images: Ji-DhoyVtEA (Colorful Bunch), ONFfU1_uODM (BF Mix), RzYTk8ALLxI (V2/Erect), -EKwJC2lmdc (Rainbrawl), _bwDYOzbkBY (Friend Like You). They are source thumbnails, not screenshots from the beginning of a round. Grass fills the remaining preview area.
- Handwritten menu labels use Patrick Hand (OFL, license in ../fonts/PatrickHand-OFL.txt); pixel HUD/prompt faces are retained from the source mod.
- `menu-music.ogg` is the source mod’s menu background loop (`freakyMenu`); it pauses before gameplay and resumes on the menu/results. No network multiplayer is included.
