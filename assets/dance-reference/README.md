The source page states CC BY-NC-ND 4.0; this record does not change that license or claim ownership of the source work.

The reference importer accepts only the normal character files and Colorful Bunch / Colorful Bunch (BF Mix). Foredoomed, horror forms, creepy audio, executable files and Lua scripts are excluded. Image frames are packed at browser-friendly resolution; soundtrack files combine the original instrumental, opponent and player stems on their unchanged time axis. The playable note timings and cast changes come from the source chart, not random generation.

The separate free-mix voice library uses both normal A/B samples from the existing local Sprunki Kiss package. Black is silent and cannot switch modes. No YouTube iframe, advertisements, recommendation feed or remote video is included in this selection.
