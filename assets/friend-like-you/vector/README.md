# Friend Like You visual reconstruction

These SVG characters and backgrounds are independently drawn code-native assets, generated by `scripts/build-friend-vector-art.cjs`. They replace the earlier mismatching generated bitmap approximations. They are not represented as the original creator's downloadable sprite sheets.

Visual reference: Neonight's Friend Like You FNF video, https://www.youtube.com/watch?v=_bwDYOzbkBY — day stage, Black solo, and final concert. Original Sprunki characters belong to Nyankobflol and their respective creators. Saved comparison references are in the local, unpublished `outputs/friend-review` folder.

The tablet layout changes the receptor positions for touch play. Desktop single-player retains the source-style upper receptor banks. Notes are drawn using the actual receptor image dimensions so moving notes and landing arrows stay the same size.
