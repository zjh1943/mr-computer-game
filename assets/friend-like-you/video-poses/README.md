# Friend Like You — complete video-reference textures

Source: Neonight's https://www.youtube.com/watch?v=_bwDYOzbkBY . These are masked pixels from local captured video frames, not the normal Sprunki costume set. See manifest.json for the frame and crop records. The local extraction script is scripts/extract-friend-video-poses.cjs; its captured screenshot inputs remain in unpublished outputs/friend-review.

Contains idle and four directional poses for Mr. Tree, Mr. Fun Computer and Black; five finale companions; both source-style health icons; Black's entrance silhouette. Computer head textures are separated from its stationary table/cable texture.

Runtime motion is authored against the shared song clock: bottom-anchored tree sway; computer head-only motion; restrained Black pose settling. No downloaded animation loop or random motion is used. Video frame cutouts can retain compression/occlusion artifacts; they are not claimed to be the creator's original sprite pack.
