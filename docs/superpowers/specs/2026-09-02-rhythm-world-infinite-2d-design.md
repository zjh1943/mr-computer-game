# 《我的节奏盒子世界》无限 2D 世界重做设计

## 目标

将现有 `rhythm-world.html` 简易原型整体替换为独立运行的 Sprunki 同人风格 2D 游戏。它不加载“电脑先生”的页面、样式或脚本。玩家能在持续生成的世界中移动、与角色交谈、选择外形、购买和装修住宅、挖地下室，并参加 Sprunki 音乐演奏与夜间四方向节奏挑战。

## 视觉方向

- 使用彩色、粗描边、扁平卡通的 Sprunki 同人画风，但不复制视频画面或原作音频。
- 世界采用俯视偏正面的固定镜头，不是横版卷轴；玩家可向上下左右移动。
- 天空为独立视差层。白天显示会眨眼和摇摆的太阳公公，多层云持续横向飘动；黄昏和夜晚使用平滑色彩过渡。
- 地面由草地、道路、花丛、树木、水塘和岩石构成。建筑使用正面可读的 2D 精灵式外观。
- Sprunki 居民以完整人物出现，而不是小图标。人物具备待机呼吸、行走摆动、说话弹跳、唱歌和跳舞状态。

## 游戏流程

1. 封面展示大量 Sprunki 角色、游戏标题、“开始游戏”和“设置”。
2. 开始游戏进入深色世界列表，显示“创建世界”和本地存档。
3. 创建世界显示 3.8 秒生成动画、下载文字和进度条。
4. 玩家在生产车间的机器中生成，初始外形为小灰人。
5. 快乐机器人头顶显示“点击对话”，询问玩家是不是好人。
6. 玩家可使用键盘输入或浏览器语音识别回复。回复后打开 Sprunki 角色选择板。
7. 选定角色后，玩家变成对应人物并离开车间，进入无限小镇。
8. 玩家探索商店、住宅、音乐广场和山洞；夜间音乐广场开启节奏挑战。

## 无限世界

### 坐标与区块

- Canvas 维护连续世界坐标，镜头跟随玩家并保留轻微移动缓冲。
- 世界划分为固定尺寸区块。进入镜头周围范围时，根据世界种子确定性生成区块。
- 同一世界种子和区块坐标始终生成相同的道路、装饰和建筑，因此离开后返回不会改变。
- 只绘制镜头附近区块，远处区块保留轻量数据，不保留大量 DOM 节点。

### 分布规则

- 出生点固定为生产车间和新手小镇广场。
- 道路用连续噪声和连接规则生成，建筑沿道路分布。
- 每隔一定距离确保出现商店、空地、住宅地块、音乐广场或山洞，避免纯随机导致长时间找不到玩法。
- 世界对象包含碰撞范围；玩家不能穿过建筑、树干、水面和大型岩石。

### 存档

- 使用 `localStorage` 保存世界种子、玩家位置、已选角色、货币、已购买住宅、家具布局、地下室状态、自定义角色和挑战最高分。
- 自动保存发生在选角、购物、装修、完成挑战和每隔固定时间。
- 世界列表提供继续游戏和重新创建世界，清空操作必须二次确认。

## 角色与对话

- 首批可选角色：Oren、Raddy、Clukr、Fun Bot、Vineria、Gray、Brud、Garnold、OWAKCX、Pinki、Simon、Sky、Durple、Mr. Sun、Mr. Tree、Wenda、Jevin、Black。
- 使用现有角色素材作为基础肖像，并在 Canvas 中绘制身体、脚底阴影和状态动画。
- 对话面板显示说话角色、逐字字幕、键盘输入按钮和语音输入按钮。
- 浏览器不支持或拒绝语音权限时，明确切换到键盘输入，不阻塞流程。
- 居民在世界中拥有简单日程：白天散步或去商店，夜晚前往音乐广场，挑战结束后回家。

## 建筑与生活玩法

### 商店

- 售卖住宅地块、墙纸、地板、灯、床、沙发、桌子、音响、钢琴和地下室装修材料。
- 购买行为即时扣除货币并加入背包；余额不足显示清晰提示。

### 住宅

- 玩家购买住宅后可选择世界中的空地放置。
- 进入住宅切换到独立室内 2D 场景，可从背包拖放家具。
- 家具吸附网格并支持移动、旋转和收回背包。

### 地下室

- 在住宅或指定洞口附近显示“挖地下室”。
- 挖掘后生成可进入的地下室场景，初始为岩壁和泥土地面。
- 装修模式允许更换墙面、地板、灯光和摆放音乐设备。

## 音乐舞台

- 音乐广场进入独立的 Sprunki 演奏界面：中央最多七名表演角色，底部为音色角色板。
- 音色分为节拍、效果、旋律和人声，以颜色区分。
- 玩家点击或拖动音色到空位后，角色换装并播放同步的原创循环；再次点击角色可静音、独奏或移除。
- 所有循环共享统一节拍时钟，在下一小节边界加入，避免声音错拍。
- “添加新角色”打开角色编辑器，可选择轮廓、颜色、面部装饰和音色类型。自定义角色可保存并加入演奏。
- 达成指定音色组合时触发原创的全员动画片段。

## 夜间节奏挑战

- 夜间音乐广场显示“音乐大挑战”，进入四轨下落式节奏玩法。
- 电脑使用方向键；手机和平板点击四个箭头判定框。
- 轨道顺序为：左、下、上、右；判定分为完美、不错、失误。
- 连击增加分数和能量；玩家分数超过对手或坚持到歌曲结束即获胜。
- 背景中的 Sprunki 角色按节拍跳舞，结束后可观看其他居民继续表演。

## 三端操作

- 电脑：方向键或 WASD 移动，空格互动，鼠标操作面板和拖放家具；节奏挑战使用方向键。
- 手机：左下虚拟摇杆移动，右侧互动按钮；节奏挑战使用屏幕底部四箭头。
- 平板：自适应更大的触控区域，世界画面保持宽视野，舞台和箭头不被拉伸。
- 触控与键盘共用同一输入状态，切换设备不会改变游戏逻辑。

## 音频

- 不复制 Incredibox、Sprunki 视频或其他受版权保护的歌曲。
- 使用 Web Audio API 合成原创鼓点、低音、旋律、效果和人声感音色。
- 音频只在玩家首次点击后启动，遵守浏览器自动播放限制。
- 设置提供主音量、音乐音量和音效音量，语言设置继续保留。

## 代码结构

- `rhythm-world.html`：页面入口、各模式容器和无脚本提示。
- `rhythm-world.css`：启动界面、HUD、对话、商店、住宅、舞台和响应式布局。
- `rhythm-world.js`：只负责应用启动和模式切换。
- `rhythm-world/engine.js`：游戏循环、Canvas、镜头和输入。
- `rhythm-world/world.js`：区块生成、碰撞、建筑和持久化对象。
- `rhythm-world/characters.js`：角色数据、绘制与状态动画。
- `rhythm-world/audio.js`：统一节拍时钟和原创音色。
- `rhythm-world/ui.js`：对话、商店、住宅、角色编辑器和通知。
- `rhythm-world/rhythm.js`：四轨挑战、判定、分数和对手逻辑。
- `rhythm-world/storage.js`：存档结构、迁移、自动保存和重置。

模块通过一个明确的游戏状态对象通信，不读取“电脑先生”的全局状态。

## 错误与降级

- Canvas 或音频初始化失败时显示可理解的错误提示和重试按钮。
- 语音不可用时自动使用键盘输入。
- 素材加载失败时使用彩色剪影占位，不使世界停止运行。
- 存档解析失败时保留损坏数据备份并创建新存档。
- 设备性能较低时减少远景装饰、云数量和粒子，但保留角色、建筑与玩法。

## 验证标准

- 独立页面不会加载 `app.js` 或 `styles.css`。
- 创建世界动画持续约 3–4 秒，之后进入生产车间。
- 玩家能通过键盘和触控向四个方向连续移动，并能跨越多个生成区块后返回原处。
- 云持续飘动，太阳公公可见且有动画，昼夜会变化。
- 快乐机器人对话、键盘输入、语音降级和角色选择均能完成。
- 商店购买、住宅放置、家具装修和地下室状态刷新后仍存在。
- 音乐舞台可同时运行多条同步原创循环，支持静音、独奏和移除。
- 夜间挑战在键盘与触控上都能完成计分和胜负流程。
- 360×800 手机、768×1024 平板和 1440×900 电脑视口均无关键控件遮挡。
- 构建输出包含新模块，托管包保持在平台大小限制内。

## 第一版交付边界

第一版完整打通所有主流程，但控制内容规模：提供一个程序化世界主题、一种住宅外观、一套地下室、八件家具、一首原创演奏组合和一首夜间挑战曲。后续可以继续增加世界主题、建筑、角色动画、歌曲和家具，而无需重写引擎。
