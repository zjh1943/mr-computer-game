# 我的节奏盒子世界：第三人称 3D 改造设计

日期：2026-09-19

## 目标

把现有俯视 2D Canvas 游戏升级为可在手机、平板和电脑浏览器运行的第三人称 3D 小镇游戏。玩家能够控制一个 Sprunki 风格角色探索无限世界，与全部普通模式角色交流，进入建筑、购物、建造、演奏和参加节奏挑战。

用户提供的角色合集图是人物正面造型参考。每个小格使用中间或中间偏下的正常角色作为该组的正面标准；不实现恐怖、受伤、流血或黑化版本。

## 成功标准

- 世界、建筑、道路、树木、山洞和室内空间具有真实 3D 深度。
- 摄像机从玩家身后跟随，可以水平旋转并适度上下观察。
- 20 个普通模式角色全部出现，补上当前版本缺少的 Tunner。
- 所有角色拥有可辨认的正面、侧面和背面；正面优先忠实于参考图。
- NPC 使用与玩家相同的角色表现系统，能转向、移动、说话和回家。
- 聊天、商店、演奏、房屋、工厂、山洞、昼夜和存档流程继续可用。
- 手机、平板和电脑分别具有合适的操作方式与画质设置。
- 最终版本通过自动测试和浏览器实际游玩验证，并只推送到 GitHub。

## 美术方向

### 立体厚片角色

角色使用“立体厚片”方案，而不是普通彩色圆柱或永远朝向镜头的平面图片：

- 正面：根据参考图绘制脸、眼睛、嘴、天线、耳朵、帽子、护目镜、藤蔓和机器零件。
- 厚度：主体使用圆润的浅厚度几何体，避免纸片感。
- 侧面：延续正面轮廓和颜色，能看到鼻口轮廓、耳朵、天线连接处和手部。
- 背面：显示头饰背面、帽檐、藤蔓根部、电线、尾部装饰或机器外壳。
- 手部：普通角色使用悬浮圆手；Mr. Fun Computer 使用电线和插头手。
- 角色没有普通人类式长腿，移动使用身体轻微弹跳和倾斜表现。

特殊角色：

- Mr. Sun 只存在于天空的昼夜系统中，不作为地面角色。
- Mr. Tree 固定生长在地面，但仍可对话和参与音乐。
- Mr. Fun Computer 是显示器机身，拥有电线插头手。
- Fun Bot 和 Garnold 保留机器外壳、面罩和机械配件。

## 3D 世界架构

### 渲染层

使用 Three.js/WebGL 替换当前 2D 世界绘制器。UI 继续使用 HTML/CSS 覆盖在 3D 画布上，保留现有菜单、聊天框、商店、舞台和节奏挑战界面。

渲染模块拆分为：

- `scene-3d.js`：场景、灯光、阴影、天空、雾和渲染循环。
- `character-3d.js`：角色模型、朝向、走路、说话和高亮状态。
- `town-3d.js`：道路、建筑、房屋、商店、音乐广场、工厂、树木和山洞。
- `camera-3d.js`：第三人称跟随、旋转、遮挡处理和设备输入。
- `world-stream.js`：依据世界种子加载和卸载玩家附近的区块。
- `interaction-3d.js`：射线点击、靠近目标、轮廓高亮和互动分发。

### 无限区块

继续使用确定性世界种子。每个区块保存地形类型、道路连接、装饰和建筑。玩家移动时只保留附近区块的 3D 对象；远处区块释放，返回时依据种子重新生成，避免无限世界耗尽内存。

小镇中心为固定区域，包含生产中心、20 个角色住宅、节拍商店、音乐广场和初始山洞。外围区块继续生成道路、住宅地块、商店、洞穴、树木和装饰。

## 摄像机和操作

### 电脑端

- WASD 或方向键移动。
- 鼠标按住拖动旋转镜头。
- 空格键互动。
- 鼠标点击角色或建筑也能互动。

### 手机和平板端

- 左侧虚拟摇杆移动。
- 右侧空白区域拖动旋转镜头。
- 独立互动按钮执行当前高亮目标。
- 点按角色或建筑直接互动。

摄像机保持在角色身后和上方，具有平滑跟随。靠近墙体时自动缩短距离，避免镜头穿进建筑。

## 角色和 NPC 行为

NPC 使用简单状态机：

1. 白天在住宅、道路、商店和音乐广场之间活动。
2. 玩家靠近时转向玩家并显示姓名提示。
3. 玩家互动时停止移动，打开对应聊天框并播放说话动作。
4. 傍晚开始沿道路返回自己的房屋。
5. 夜间进入房屋，部分角色可以在音乐挑战期间前往广场。

每个 NPC 使用确定的角色专属台词，不随机套用其他角色回复。

## 互动流程

- 角色：发光轮廓 → 名字提示 → 聊天框 → 专属台词。
- 商店：高亮招牌 → 打开商品界面 → 购买后更新金币和背包。
- 音乐广场：进入演奏场景 → 分配角色和音色 → 开始合奏或节奏挑战。
- 房屋：门动画 → 室内 3D 房间 → 放置家具和装修。
- 工厂：门动画 → 生产室 → 可再次从门离开。
- 山洞：挖掘动画 → 创建地下室入口 → 进入地下室装修。

按钮、键盘空格和射线点击共用同一个互动目标，防止不同输入得到不同结果。

## 昼夜系统

太阳沿天空弧线移动，接近日落时显示“再见，我明天再来！”，然后完全消失。月亮从另一侧升起，夜间只显示月亮和星星；月亮落下后太阳重新升起。

昼夜状态同时控制天空颜色、主光方向、阴影、路灯、HUD 时间、NPC 日程和夜间音乐挑战。

## 存档兼容

存档升级到新版本，但读取旧存档时保留：

- 世界种子。
- 玩家角色、金币和位置。
- 背包、房屋、家具和地下室。
- 自定义角色、舞台槽位和最高分。
- 音量与语言设置。

旧的平面坐标转换为 3D 的 `x/z` 坐标，地面高度由新区块决定。升级失败时保留原始存档副本并创建安全的默认位置。

## 性能和设备适配

- 电脑：较远视距、实时阴影、更多装饰。
- 平板：中等视距、主要角色阴影、适量装饰。
- 手机：较近视距、简化阴影、较少装饰和粒子。
- 自动检测 WebGL；不支持时显示明确提示，不继续运行损坏画面。
- 模型和贴图分批加载，生成世界界面显示真实加载进度。

## 错误处理

- 角色资源缺失时使用带名字的安全占位模型，并记录错误。
- 区块生成失败时跳过该区块，不中断整个游戏。
- WebGL 上下文丢失时暂停游戏并显示恢复提示。
- 存档迁移异常时不覆盖旧存档。

## 测试与验收

自动测试覆盖：

- 20 个角色清单、特征和特殊角色规则。
- 角色前、侧、背三个方向的模型部件。
- 摄像机跟随、旋转范围和墙体遮挡。
- 键盘、摇杆、触摸拖动、按钮和射线点击。
- 聊天、商店、演奏、房屋、工厂和山洞互动。
- 区块加载/卸载和固定小镇内容。
- 昼夜互斥、太阳告别、NPC 回家和夜间挑战。
- 旧存档迁移与失败回退。

浏览器验收覆盖电脑尺寸、平板尺寸和手机尺寸，并检查控制台错误、画面布局、主要交互和性能。

## 非目标

- 不制作任何恐怖阶段或血腥内容。
- 不加入多人联网、账号、聊天服务器或付费系统。
- 不在本阶段制作复杂物理破坏或战斗系统。
- 不发布到 ChatGPT Sites；完成后只推送 GitHub，供 GitHub Pages 使用。
