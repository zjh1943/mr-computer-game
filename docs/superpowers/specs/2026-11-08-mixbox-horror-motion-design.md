# 音乐站恐怖动作设计

## 目标

让音乐站中的 Pyramixed 角色不再只按固定六张图轮换；角色演奏时需要有连续的正面、左右侧面、背面、回弹和眨眼状态。主页点击“恐怖之夜”时，舞台和底部角色栏必须同步变为当前版本对应的恐怖形态。

## 已有基础

- 原版角色沿用 `DanceCast` 的原始动作帧和音频。
- Pyramixed 已有本地四方向 SVG 与本地 WAV 音频，位于 `assets/sprunki-versions/pyramixed/`。
- 主页用 `body.terror-night` 表示恐怖之夜。

## 选择

采用资料驱动的动作序列：每拍为角色写入 `data-view` 和 `data-pose`，CSS 负责眨眼、起跳、侧身、回弹和恐怖静电。恐怖形态不混用：原版沿用原版图帧并加原版恐怖舞台处理；Pyramixed 继续使用其四方向图并加 Pyramixed 独立的恐怖处理。这样能保留现有本地素材和离线声音，也能让恐怖开关即时生效。

## 不做的事

- 不下载或嵌入外站视频。
- 不替换用户已有的主页面恐怖开关逻辑。
