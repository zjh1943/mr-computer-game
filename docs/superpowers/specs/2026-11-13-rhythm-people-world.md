# 节奏盒子人世界设计

游戏从角色图标选择开始，玩家以所选角色出生在原版村。世界继续使用现有的 3D 流式区块，中心是熟悉的原版村，向外扩展为按角色风格分类的村庄以及带高楼、道路和居民的城市区。

NPC 不再只是重复台词。每个 NPC 保存对玩家的好感、是否得到过玩家帮助、是否曾拒绝帮助玩家，以及最近一次谈话的语气。玩家友善回复，NPC 会更友善；玩家说难听的话，NPC 会不高兴并用不友善但不辱骂的方式回应。玩家在 NPC 遇到困难时不帮忙，之后玩家请求帮助时，该 NPC 可以拒绝，并说明原因。

取消右下角“互动”圆钮。靠近可交谈角色时，在角色上方出现“点击对话”，点击角色打开对话界面。建筑、商店、舞台仍通过直接点击进入。

屏幕底部增加九格物品栏。初始提供稿子。选中稿子并对准山洞或可挖掘地面时显示“挖地道”，完成后保存地道位置。现有摇杆、菜单、合唱按钮保留。

第一阶段保证入口可从 GitHub Pages 打开，并完成角色选择、关系记忆、点击对话、物品栏和挖地道这一条可玩闭环。更多角色村和城市居民数量在后续区块内容中继续增加。
